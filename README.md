# Приложение по подбору фильмов
Приложение предполагает функции: случайного выбора фильма, авторизации (авторизованные пользователи будут шифроваться уникальным кодом), сохранение
понравившихся фильмы. Так же приложение будет иметь рейтинг фильмов (с использованием внешнего API) и фильтры по выбору фильма.
При этом будут использованы: бд с информациями о фильме, бд с шифрованными логинами и паролями пользователей и Qt (для графического интерфейса)
